# ChainerTrader 
Implement TradvingView Algorithms of Youtube Channel Shi Hun


## Install it from PyPI

```bash
pip install trader
```

## Usage

```bash
$ python -m trader -h
or
$ trader -h
```

## Show trader version 

```bash
$ trader -v
```

## Display command line parameters

```bash
$ trader -h
```

## Run trader with `ShihunMACD` strategy

```bash
$ trader --strategy=ShihunMACD
```
